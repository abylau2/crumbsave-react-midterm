# Image credits

CrumbSave stores these Unsplash-hosted food photographs locally so the production UI does not rely on runtime image services. The [Unsplash License](https://unsplash.com/license) permits use without required attribution; this list preserves source provenance. Photographs illustrate food categories; the restaurants and cafes pictured are not presented as partners or as the named example businesses. Existing file names were kept so listings already saved in browser storage continue to load their images.
